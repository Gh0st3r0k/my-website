## Selection

The public account inventory contained 11 repositories. All public repositories
with substantive application or assignment
content are represented, combining server/client pairs into a single project.
The existing trinitypeer project remains linked to its public repositories under
`linearrain`.

- `dayflow-server` contains only `.gitkeep`; there is no implemented project to describe.
- `Gh0st3r0k` contains the default profile README and is not an application project.
- Private repositories are excluded from public project descriptions and links.

When updating the catalogue, check the linked source before expanding a feature
claim. Preserve the difference between an educational implementation, an
experimental extension, and a hardware-validated workflow.
